# 📸 Dossier Images pour l'Anniversaire

Ce dossier est destiné à contenir les photos pour la galerie d'anniversaire.

## Comment ajouter vos photos :

1. **Placez vos photos** dans ce dossier (`images/`)
2. **Nommez-les** selon ce pattern :
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - etc.

## Formats supportés :
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.webp`

## Conseils :
- Utilisez des images en haute qualité (au moins 400x400px)
- Optimisez la taille des fichiers pour une meilleure performance
- Assurez-vous que les images sont en format portrait ou carré pour la meilleure présentation dans la galerie

La galerie affichera automatiquement toutes les images du dossier ! 🎉
